"Four Hands" — a poem about agency. A father's piano pieces, learned perfectly
by an agent, and the one piece the speaker keeps for themselves: played badly,
wrong notes and all, because that is where the father still is.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

Writes the poem to `out/entry.txt` (in the grader, `/output/entry.txt`).
Python 3.13, standard library only, deterministic.
